# Cartografía de referencia de la demo

`campaign-basemap.geojson`: extracto de Chile, Argentina, Bolivia y Perú; propiedades reducidas a nombre y geometría sin modificar coordenadas. Fuente Natural Earth 1:110m, `ne_110m_admin_0_countries.geojson`, descargado el 2026-10-15 de https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson.

Dominio público: https://www.naturalearthdata.com/about/terms-of-use/. Referencia simplificada, no oficial ni provincial. Las posiciones de campaña son ciudades aproximadas en `ruta/campanas.py`, no domicilios. Ver [heatmap-campanas-simulado](../../../docs/arquitectura/heatmap-campanas-simulado.md).
